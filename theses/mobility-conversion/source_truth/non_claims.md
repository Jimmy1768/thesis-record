# Non-Claims

Status: candidate guardrail.

Mobility Conversion does not currently claim:

- that any MTR is best;
- that any country has the best transport;
- that GDP determines transport quality;
- that livability rankings measure usable access;
- that transit reputation is evidence of access performance;
- that congestion fame is evidence of system failure;
- that walkability reputation is evidence of universal access;
- that a single composite score is valid;
- that explanatory axes are score components;
- that any MTR should be selected for study because it is famous, admired, or
  intuitively interesting.

This thesis is not currently:

- a country ranking;
- a GDP ranking;
- a livability index;
- relocation advice;
- a best-transit-cities list;
- a final scorecard;
- a finished paper.
