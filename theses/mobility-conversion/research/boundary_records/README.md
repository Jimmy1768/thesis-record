# Boundary Records

Status: empty holding folder. No MTR boundary records are approved or present.

This folder is reserved for future filled boundary records for proposed
Metropolitan Transport Regions.

Do not add a filled record here unless:

- the proposal is source-led;
- the operator is not selecting by reputation, familiarity, or rankings;
- the record follows
  `theses/mobility-conversion/research/boundary_record_template.md`;
- the boundary source decision record permits the source class to be tested;
- the record begins as `not_admitted`.

No file in this folder should be treated as final candidate selection, final
boundary methodology, scoring, ranking, or paper evidence.
