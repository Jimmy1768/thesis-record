# Evidence Plan

Status: formation-stage plan. No evidence has been accepted.

## Evidence Intake Rule

Evidence must enter through verified source notes, manifests, or explicitly
marked rejected material. External query tests and Deep Research returns are not
evidence.

Deep Research returns must first be processed through
`theses/mobility-conversion/research/deep_research_return_protocol.md`.

## Candidate Source Classes

Potential source classes to evaluate:

- metropolitan and regional transport agencies;
- national statistical agencies;
- GTFS and service availability datasets;
- travel surveys;
- accessibility datasets;
- safety databases;
- infrastructure asset condition reports;
- affordability and household expenditure data;
- academic transport-access literature;
- governance and institutional records.

## First Evidence Questions

- Which source classes can define MTR boundaries consistently?
- Which sources measure usable access rather than reputation?
- Which sources are comparable across regions?
- Which outcome dimensions require local sources and which can use global or
  regional datasets?
- What source gaps would force narrowing of the thesis?

The usable-access outcome decision is recorded in
`theses/mobility-conversion/research/usable_access_methodology_decision_record_2026-06-28.md`.
