# Method Test Decision: No Proposed-MTR Dry Run Yet

Date: 2026-06-28

Status: formation-stage decision. No candidate MTR selected.

## Decision

Do not run a proposed-MTR dry run yet.

Continue to allow source-family dry runs. A proposed-MTR dry run requires an
explicit source-led trigger and must be labeled dry-run-only.

## Rationale

The OECD FUA source-family dry run showed that the workflow can validate a
source family and stop before naming a region.

Running a proposed-MTR dry run now would require naming a real region before a
source-led proposal exists. That would risk leaking reputation, familiarity, or
convenience into candidate formation.

## Consequence

Boundary methodology is sufficient for the next stage of formation work.

The active methodology focus should shift to usable-access outcome design:

- define what the outcome dimensions mean;
- define evidence standards;
- define failure and missingness rules;
- prevent usable access from becoming a transit ranking, livability score, or
  data-rich-city proxy.

## Non-Decisions

This decision does not:

- prohibit future proposed-MTR dry runs;
- admit any MTR;
- create a candidate ledger;
- decide final boundary methodology;
- approve outcome metrics or scores.
