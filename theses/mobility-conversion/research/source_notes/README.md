# Source Notes

Status: active formation-stage source-note directory.

Source notes belong here only after independent inspection of the underlying
source. Deep Research returns and prompt outputs should not be copied here as
evidence.

Use:

- `theses/mobility-conversion/research/source_note_verification_protocol.md`
- `theses/mobility-conversion/research/source_note_template.md`

A source note verifies and classifies a source. It does not by itself admit an
MTR, accept a metric, create an evidence manifest, authorize a raw data archive,
score, rank, or make final paper claims.
